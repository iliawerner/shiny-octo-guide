# shiny-octo-guide

Это простое веб-приложение для составления случайного недельного плана готовки на мультиварке OL550EU.

## Запуск

1. Откройте терминал и перейдите в папку проекта.
2. Запустите встроенный http‑сервер Python:
   ```bash
   python3 -m http.server 8000
   ```
3. Откройте браузер и перейдите по адресу [http://localhost:8000/index.html](http://localhost:8000/index.html).
4. Нажмите кнопку **«Сгенерировать план на неделю»**, чтобы получить рецепты. Каждый рецепт можно заменить на случайный, нажав **«Заменить»**.

Все рецепты адаптированы для режима готовки в устройстве OL550EU.
